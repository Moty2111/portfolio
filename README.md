# Moty — Portfolio

> Витрина моих проектов: веб-приложения, игры, 3D-открытки и телеграм-боты.

**🔗 Живая версия: [moty2111.github.io/portfolio](https://moty2111.github.io/portfolio/)**

---

## Что это

Одностраничный сайт-портфолио, собранный без фреймворков и сборки — чистые HTML, CSS и JavaScript. Тёмная неоновая тема по умолчанию, светлая переключается кнопкой в шапке. Весь интерфейс и описания проектов доступны на русском и английском.

## Возможности

- **16 проектов** с фильтрами по категориям (приложения, игры, открытки, мобильные, боты) и живым поиском — по названию, описанию, стеку и году
- **Карточки-модалки** с галереей скриншотов, деталями работы и ссылками на демо и исходники
- **Две темы** и **два языка** с сохранением выбора в `localStorage`
- **Живые демо** внутри репозитория для проектов без GitHub Pages
- Полностью адаптивная вёрстка, анимации появления, ловушка фокуса и управление с клавиатуры
- Собственная OG-картинка для красивых превью в соцсетях

## Стек

`HTML5` · `CSS3` (custom properties, grid, backdrop-filter) · `Vanilla JavaScript` (ES2020) · `IntersectionObserver` · `localStorage`

Без зависимостей, без сборки — только три файла и ассеты.

## Структура

```
portfolio/
├── index.html          # разметка и SVG-спрайт иконок
├── css/style.css       # токены тем, компоненты, адаптив
├── js/data.js          # проекты, стек, переводы RU/EN
├── js/app.js           # рендер, фильтры, поиск, модалки, темы
├── assets/
│   ├── shots/          # скриншоты проектов
│   ├── favicon.svg
│   └── og.jpg          # превью 1200×630
└── demos/
    ├── race/           # 3D-гонки (Three.js)
    └── strityxa/       # «Футбольный мир» — первый сайт
```
